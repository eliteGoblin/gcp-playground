# gcp-playground

Demo GKE platform. Terraform is in `terraform/` (bootstrap, modules, envs). Design documents are in `docs/`. Local-only files go in `output/` (gitignored).

## Agent self-learning

Role memories are in `.claude/agents/memory/`: `<role>.md` per role and `_shared.md` for all roles. Read them before substantive work. Add a lesson only after a mistake, a false verification, a system quirk, or a new procedure that verifiably worked.
